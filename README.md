# Arduino-Nano-Drone

This is one of my most advanced projects yet, it is a drone with Arduino Nano as the MCU, and a custom made Flight controller PCB.
It is a quadcopter, has ESCs for each of the motor, and is relatively quite cheap.
It can be controlled by your phone as it has a HC-05 module. It can also be controlled with a transmitter NRF24L01+PA+LNA.
